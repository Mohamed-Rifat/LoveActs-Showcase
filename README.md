## Overview

LoveActs is an interactive web platform that combines flower delivery with café services. Customers browse and order products, and the business team manages everything through an engaging admin dashboard.

## ✨ Key Features

- 🛍 Product browsing and ordering with a smooth, animated UI
- ☕ Partner cafés section
- 📋 Admin dashboard for managing orders
- 🧾 Export orders as **PDF** or **image** and print invoices
- 📈 Charts and statistics
- ✅ Validated forms and real-time notifications
- 📱 Fully responsive across devices

## 🛠 Tech Stack

| Area | Technology |

| Forms | Formik · Yup |
